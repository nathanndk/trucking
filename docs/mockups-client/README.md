# LINTAS — Client Mockups

This package contains 34 full-page PNG mockups generated from isolated demo data.

- `desktop/`: 17 pages at a 1440 × 1000 viewport
- `mobile/`: 17 pages at a 390 × 844 viewport

Included public pages: home, about, services, fleet, coverage, projects, contact, and 404.

Included CMS pages: login, dashboard, services, fleet, coverage, projects, clients, inquiries, and settings.

The CMS screenshots use a temporary mockup account and do not expose production credentials or data.
